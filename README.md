# 🦉 Матэматычны трэнажор — 6 клас

Займальны вэб-дадатак для трэніроўкі матэматыкі за 6 клас. Мэта — падняць адзнаку да **10 па 10-бальнай шкале**,
зрабіўшы навучанне цікавым: гульнявыя ўзнагароды, адаптыўная складанасць і зразумелы дашборд прагрэсу.

Дадатак цалкам статычны (HTML/CSS/JS), без сервера, без інтэрнэту і без рэгістрацыі — прагрэс захоўваецца ў браўзеры.

## Што ўмее
- 9 тэм 6 класа: натуральныя лікі, звычайныя і дзесятковыя дробы, працэнты, адмоўныя лікі,
  ураўненні, прапорцыі, плошча/перыметр, тэкставыя задачы.
- **Ацэнка 1–10** за кожную сесію і агульная; мэта — давесці да 10.
- Адаптыўная складанасць (узровень 1–10 расце/падае па поспеху), ухіл на слабыя тэмы.
- XP, узроўні, серыя дзён (streak), знакі-дасягненні, талісман-сава, канфеті, гук (выключаецца).
- Дашборд: дакладнасць па тэмах, слабыя тэмы, знакі, прагрэс. Штодзённая мэта.
- Поўнасцю па-беларуску, адаптыўна пад тэлефон і камп'ютар.

## Хуткі старт (5 секунд)
1. Адкрый файл **index.html** у любым браўзеры (двойчы клік).
2. Абяры «Змяшаная трэніроўка» або канкрэтную тэму — і наперад.

Для заняткаў на **тэлефоне** трэба, каб файлы раздаваў сервер — глядзі ніжэй.

## Як даць малодшаму брату
### Варыянт A — той жа Wi-Fi (хутка і бяспечна)
1. На камп'ютары запусці **start-server.bat** (Windows) або **start-server.sh** (macOS/Linux).
2. У кансолі з'явіцца адрас выгляду `http://192.168.x.x:8080` (бяры лакальны IP камп'ютара).
3. Адкрый гэты адрас на тэлефоне брата — калі ён у той жа сетцы Wi-Fi.

### Варыянт B — публічная спасылка (працуе з любой сеткі)
Выкарыстай бясплатны Cloudflare Tunnel:
1. Спампуй `cloudflared` (аднафайлавая ўтыліта) з github.com/cloudflare/cloudflared/releases.
2. Запусці сервер: `python -m http.server 8080`.
3. У другім акне: `cloudflared.exe tunnel --url http://localhost:8080`.
4. У логах з'явіцца спасылка `https://....trycloudflare.com` — яе і дай брату.
(Спасылка часовая, пакуль працуе камп'ютар; для сталай — варыянт C.)

### Варыянт C — пастаянны хост (рэкамендавана для «заўсёды») ⭐
Самы просты спосаб — **Netlify Drop**:
1. Зайдзі на https://app.netlify.com/drop
2. Перацяні ў вакно ўвесь гэты файл-набор (або ZIP).
3. Атрымаеш пастаянную спасылку выгляду `https://xxxx.netlify.app` — ёю можна дзяліцца назаўжды.
Альтэрнатыва — GitHub Pages (запампуй файлы ў рэпазіторый і ўключы Pages).

## Як карыстацца
- Сесія = 10 пытанняў. Уводзь адказ у поле (можна адмоўныя лікі і дробы праз коску/кропку) і цісні Enter.
- Пасля адказу — падказка і тлумачэнне. «Далей» вядзе да наступнага.
- У канцы — адзнака 1–10. «Дашборд» паказвае прагрэс, слабыя тэмы і знакі.
- Прагрэс захоўваецца аўтаматычна; кнопка «Скінуць прагрэс» — калі трэба пачаць спачатку.

## Файлы
- `index.html`, `styles.css`, `app.js` — сам дадатак.
- `start-server.bat` / `start-server.sh` — запуск лакальнага сервера ў адзін клік.
- `README.md` — гэтае апісанне.

## Для старэйшага (тэхнічныя ноты)
- Ніякіх залежнасцей і зборкі. Чысты статычны сайт.
- Лакальна: `python -m http.server 8080 --bind 0.0.0.0` у гэтай папцы.
- Хостынг: любы статычны (Netlify, GitHub Pages, Cloudflare Pages, Vercel).
- Даныя захоўваюцца ў `localStorage` браўзера пад ключом `mt6_state_v1`.
