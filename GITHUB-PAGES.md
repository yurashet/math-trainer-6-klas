# Публікацыя на GitHub Pages (пастаянная бясплатная спасылка)

1. Ствары рэпазіторый на github.com (напрыклад `math-trainer`), публічны.
2. Запампуй у яго ўсе файлы з гэтай папкі (index.html, styles.css, app.js і інш.) у корань.
   Можна праз вэб-інтэрфейс «Add file → Upload files».
3. Зайдзі ў Settings → Pages.
4. У «Build and deployment» абяры Source: **Deploy from a branch**, Branch: **main**, folder: **/(root)**, Save.
5. Праз хвіліну спасылка будзе выгляду: `https://<твой-лагін>.github.io/math-trainer/`.
6. Файл `.nojekyll` ужо ў папцы — ён патрэбны, каб GitHub не апрацоўваў сайт праз Jekyll.

Гатова — гэтую спасылку можна даваць малодшаму брату назаўжды.
